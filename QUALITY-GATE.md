# Review quality gate

- [ ] The diff maps directly to the stated outcome.
- [ ] There is no unrelated formatting, renaming, dependency churn, or generated noise.
- [ ] Public contracts and compatibility impact are called out.
- [ ] Error, empty, retry, and partial-failure behavior is intentional.
- [ ] Tests would fail for the original defect or missing capability.
- [ ] The handoff states what was not verified.

# AgentBrief Free Starter

Turn vague coding-agent requests into bounded, verifiable work.

This starter contains three practical building blocks:

- `AGENTS.md` — repository rules for a full-stack product.
- `BUG-BRIEF.md` — a five-minute bug-fix brief.
- `QUALITY-GATE.md` — a compact review checklist.

## Use it

1. Copy the files you need into your repository.
2. Replace every `[BRACKETED PLACEHOLDER]`.
3. Delete rules that do not apply.
4. Give the completed brief to your coding agent.

Build a custom brief with the free [AgentBrief generator](https://agentbrief-launch.groovy-vine-6579.chatgpt.site/).

## Pro kit

AgentBrief Pro adds 43 production-ready assets: 18 `AGENTS.md` templates, 12 task briefs, 8 recovery playbooks, and 5 quality gates.
